# Kore 概览

Kore 是一门通用语言，重点让**自举编译器、操作系统内核、虚拟机/解释器**这三类程序既贴近机器又保有高级抽象。

## 1. 设计取舍

优先级明确，冲突时按此顺序裁决：

1. **可预测性优先于便利性** — 没有隐藏的内存分配、隐藏的控制流、隐藏的运行时。读到的代码就是生成的代码。
2. **零运行时可选** — freestanding 模式不需要 libc、不需要 GC、不需要栈展开元数据。
3. **编译期求值代替宏** — 没有预处理器、没有文本宏。泛型、代码生成、静态查表统一由编译期求值完成。
4. **语法易于机器解析** — 自举编译器要解析自己，所以刻意避开 `<>` 泛型歧义，避开"必须先知道类型才能消歧"的构造。
5. **少而正交** — 关键字 23 个，每个记号只有一个含义。

明确不做的事：

| 不做 | 原因 |
| --- | --- |
| GC | 内核与实时代码不能容忍不可预测停顿 |
| 异常 / 栈展开 | 需要运行时元数据，freestanding 无法使用 |
| 实现继承（`class extends`） | 脆弱基类问题；trait + 嵌入可表达同样复用 |
| 预处理器 / 文本宏 | 破坏工具链与可读性，编译期求值已够用 |
| 隐式数值转换 | 底层代码里宽度与符号必须显式 |
| 任意运算符重载 | 只允许在指定 trait 内实现，避免阅读时的意外开销 |

## 2. 六个统一记号

这是 Kore 与其他语言差异最大的部分。每个符号在**所有位置**都是同一个意思，学会六个就覆盖了大部分语法。

| 记号 | 唯一含义 | 例子 |
| --- | --- | --- |
| `~` | **可变** | `~x := 0`（可变绑定）、`~i32`（可变类型）、`~^T`（可变指针）、`~^self`（可变接收者） |
| `::` | **编译期绑定** | 类型、函数、常量、泛型全部用它；顺序无关 |
| `:` | **运行期绑定** | 局部变量、字段；顺序敏感 |
| `^` | **指针** | 类型位 `^T`；前缀 `^x` 取址；后缀 `x^` 解引用 |
| `?` | **分支** | 唯一的条件构造，同时覆盖 if / else / switch / match |
| `@` | **循环** | 唯一的循环构造，同时覆盖 for / while / foreach / loop |
| `[T]` | **泛型** | 用方括号而非 `<>`，彻底消除解析歧义 |

## 3. 关键字全表

共 23 个，按用途分组。语法的重量落在六个记号上，所以关键字只承担记号表达不了的语义。

| 组 | 关键字 | 用途 |
| --- | --- | --- |
| 声明 | `pub` `impl` `trait` `use` | 导出、挂方法、声明接口、导入与嵌入 |
| 类型 | `own` `vol` `dyn` `as` `is` | 所有指针、易变访问、动态派发、类型转换、匹配引导 |
| 控制 | `ret` `jmp` `stop` `skip` `defer` | 提前返回、保证尾调用、跳出、下一轮、作用域退出 |
| 逻辑 | `and` `or` `not` | 布尔运算（写成词，避免与位运算记号混淆） |
| 位运算 | `xor` `inv` `rol` `ror` | AND / OR 用 `&` / `\|`；`^` 归指针、`~` 归可变，故 XOR 与取反用词形 |
| 其他 | `asm` `unsafe` | 内联汇编、突破检查 |

对照：C 有 32 个关键字、Rust 有 39 个、Go 有 25 个。Kore 少的部分不是靠省略功能，而是靠 `?`/`@` 各自吞掉一整族关键字。

`true` `false` `nil` `self` `Self` 是字面量与内置名字，不计入关键字。

## 4. 一眼概览

```kore
use std.io

Shape :: .Circle(f32) | .Rect(f32, f32)

area :: (s Shape) f32 => ? s is {
  .Circle(r)  => 3.14159 * r * r
  .Rect(w, h) => w * h
}

main :: () void ! io.Err => {
  shapes := [Shape.Circle(1.0), .Rect(2.0, 3.0)]
  ~total := 0.0
  @ shapes => s { total += area(s) }
  io.out.print("total: {}\n", total)!
}
```

五个记号（`::` `:=` `~` `?` `@`）、两个关键字（`use` `is`），就写完了一个带和类型与穷尽匹配的完整程序。
