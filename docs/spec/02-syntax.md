# 语法

## 1. 绑定

`~` 前缀表示可变，规则在任何位置都一致。

```kore
x := 42            -- 不可变，类型推断为 i32
~x := 42           -- 可变
x : i64 = 42       -- 不可变，显式类型
~x : i64 = 42      -- 可变，显式类型

x = 43             -- 赋值（仅当 x 用 ~ 声明）
a, b = b, a        -- 并行赋值，右侧先全部求值
```

不可变是默认值，没有 `const` 关键字。

`::` 是编译期绑定，`:` 是运行期绑定。这一条区分贯穿全语言：

```kore
MAX  :: 4096                      -- 编译期绑定到一个整数值
Vec3 :: {x, y, z f32}             -- 类型（也是编译期绑定）
dot  :: (a, b Vec3) f32 => ...    -- 函数

n : usz = read_len()              -- 运行期
```

编译期绑定**顺序无关**，可以互相前向引用；运行期绑定顺序敏感。这让单遍解析的自举编译器不必做前向声明。

## 2. 函数

参数写成 `名字 类型`，同类型可合并。返回类型紧跟参数表，`=>` 引出函数体。

```kore
add  :: (a i32, b i32) i32 => a + b
dot  :: (a, b Vec3) f32   => a.x*b.x + a.y*b.y + a.z*b.z
log  :: (msg str) void    => io.out.write(msg)
```

块体用 `{}`，**最后一个表达式即返回值**，不需要 `ret`：

```kore
gcd :: (a, b u64) u64 => {
  ~x, ~y := a, b
  @ y != 0 {
    x, y = y, x % y
  }
  x                    -- 返回值
}
```

`ret` 只用于提前返回。

## 3. 分支 `?`

一个记号覆盖 if / else if / else / switch / match。三种形态。

**守卫** —— 单臂，无花括号，用于早退和断言：

```kore
? x < 0 => ret .Err(.Neg)
? not ready => ret nil
```

**条件链** —— `?` 紧跟 `{`，臂的左边是布尔表达式，`_` 是兜底：

```kore
grade := ? {
  s >= 90 => "A"
  s >= 80 => "B"
  s >= 60 => "C"
  _       => "F"
}
```

**匹配** —— `?` 后跟被检查的表达式，再跟 `is`，臂的左边是模式：

```kore
? tok is {
  .Num(n)      => eval_num(n)
  .Sym(s)      => lookup(s)!
  .List([h, ..t]) => apply(h, t)!
  .Nil         => nil
}
```

联合的匹配是穷尽的：漏掉变体是编译错误，不需要写 `_`。

## 4. 循环 `@`

一个记号覆盖 while / for / foreach / loop。三种形态。

**条件循环** —— 条件在前，条件省略则永远循环：

```kore
@ y != 0 { x, y = y, x % y }
@ { work() }            -- 无限循环
```

**范围循环** —— `..` 产生半开区间，`..=` 产生闭区间：

```kore
@ 0..n => i { arr[i] = i * i }
@ 0..=255 => b { crc = update(crc, b as u8) }
```

**迭代循环** —— 直接遍历 slice 或任何实现 `Iter` trait 的类型：

```kore
@ items => it { process(it) }
@ map.kv() => k, v { log(k, v) }  -- 解构
```

控制流：`stop` 跳出，`skip` 进入下一轮。

## 5. 块、表达式与闭包

所有构造都是表达式，块的最后一行是块值。`ret` 只用于提前返回，`\` 引出闭包：

```kore
n := { ~acc := 0 ;  @ items => it { acc += it } ;  acc }

double  :: \x i32 => x * 2            -- 参数表写法与函数一致
add     :: \a, b i32 => a + b         -- 同类型合并
reducer :: \acc i64, x i64 => acc + x
```

闭包不写返回类型，由体推断。参数类型能由上下文定下来时也可省略，这是管道里最常见的形态：

```kore
items |> filter(\x => x > 0)          -- x 的类型来自 items 的元素类型
```

管道 `|>` 把左侧值注入右侧函数的第一个参数，可链式：

```kore
items |> filter(\x => x > 0) |> map(\x => x * x) |> sum()
```

`;` 是臂分隔符，在需要连接多个表达式时也作语句分隔。
