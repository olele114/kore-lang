# 类型系统

强类型、无隐式转换、局部类型推断（Hindley-Milner 风格的双向推断，但不跨函数边界推断签名 —— 签名必须显式，这让增量编译和错误信息都可控）。

## 1. 基础类型

```kore
i8 i16 i32 i64         -- 有符号
u8 u16 u32 u64         -- 无符号
usz isz                -- 指针宽度整数，独立 nominal 类型（不是 u64/i64 的别名）
f32 f64                -- 浮点
bool                   -- true / false
void                   -- 单位类型，只有一个值
never                  -- 不返回（发散）
```

**任意宽度整数** `u1 … u64` / `i1 … i64` 是一等类型，直接对应硬件寄存器字段：

```kore
enable   : u1  = 1
prescale : u3  = 0b101
addr     : u20 = 0x1_F000
```

这消除了 OS 代码里绝大多数手写移位掩码。

`i128` / `u128` 也存在，但不属于任意宽度序列 —— 它们跨越寄存器宽度，运算由编译器展开为多字序列。`u65 … u127` 不提供。

## 2. 溢出语义

```kore
a + b        -- debug 下溢出即 panic，release 下为 UB 前提（可用 -ftrap 强制）
a +% b       -- 环绕（wrapping）
a +| b       -- 饱和（saturating）
a.add_ck(b)  -- 返回 i32?，溢出为 nil
```

`-% *% <<%` 同理。默认版本会检查，是刻意的：内核里静默环绕是 bug 来源。

## 3. 结构与元组

```kore
Vec3  :: {x, y, z f32}
Pair  :: (i32, str)              -- 元组类型

p := Vec3{1.0, 2.0, 3.0}         -- 位置初始化
q := Vec3{x: 1.0, z: 3.0, ..0}   -- 命名 + 其余填 0
t := (7, "hi")
t.0                              -- 元组取字段
```

## 4. 联合与变体

`|` 声明和类型（sum type）。变体用 `.Name` 引用，可携带数据：

```kore
Token :: .Num(i64) | .Sym(str) | .List([]Token) | .Nil

Expr :: .Lit(i64) | .Var(str) | .Add(own ^Expr, own ^Expr)
```

匹配必须穷尽（`?` 的匹配形态自动检查）。联合的内存布局由编译器决定：最宽变体 + 判别字段，`#packed` 可进一步控制。

## 5. 可选类型 `T?`

`T?` 等价于 `T | nil`，是对联合的语法糖。`nil` 只能用于可选类型，不是指针的默认值：

```kore
find :: (arr []i32, v i32) usz? => {
  @ 0..arr.len => i {
    ? arr[i] == v => ret i
  }
  nil
}

r := find(arr, 7)
? r is {
  nil  => log("not found")
  n    => log(n)
}
```

`r?.field` 链式访问：`r` 为 `nil` 时整个表达式求值为 `nil`。

返回位置上裸 `T` 值自动提升为 `T?`（`find` 里的 `ret i` 就是），所以只有 `nil` 需要写出来。

## 6. 数组、切片与字符串

```kore
[4]u8      -- 栈上固定长度数组
[]u8       -- 切片：指针 + 长度，不拥有内存
own []u8   -- 拥有切片

buf : [512]u8
s   : []u8 = buf[8..64]    -- 半开切片
s2  : []u8 = buf[8..=63]   -- 闭合切片

str          -- 内置字符串类型，底层是 []u8（UTF-8），内容不可变
```

字符串字面量类型是 `str`，`str.bytes()` 返回 `[]u8`。

`str` 没有可变形态 —— 可变性是绑定属性，`~s : str` 表示可重新绑定，不表示可改内容。需要可变文本时用 `~[]u8` 或 `~[N]u8`。

## 7. 类型转换

所有转换必须显式，`as` 是唯一的转换记号：

```kore
x : u8  = 200
y := x as i32       -- 零扩展
z := x as i8        -- 截断（200 → -56），合法但你负责语义
p := 0x4000_0000 as ^UartRegs   -- 整数转指针，需要 unsafe
```

`unsafe { }` 块包裹任何突破编译器检查的操作。没有隐式转换，没有 C 风格提升。
